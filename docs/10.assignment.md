# 10. Assignment

Practise the whole loop: your own repo, on GitHub, cloned to the server, run
there, results back. The code is given — copy
[`assignment/train.py`](../assignment/train.py) as it is. Nothing is handed in.

The script uses the GPU if there is one and falls back to the CPU if not, so
the same file runs on your laptop and on the server.

## Do

- add `train.py`, a short `README.md`, and a `.gitignore` containing `results/`
- test it on your own machine first, small and quick: `python3 train.py --epochs 20 --samples 1000`
- commit the README and `.gitignore` first, `train.py` second — two commits, real messages
- push, and check on github.com that `results/` is not there
- `ssh` to the server
- clone your repo on the server and cd into it
- start a session: `tmux new -s training`
- run it: `python3 train.py --epochs 5000`
- detach with `Ctrl+B` `d` and log out
- log back in, `tmux ls`, `tmux attach -t training`
- copy the result back, **from your laptop**: `scp USER@SERVER:~/torch-demo/results/loss.csv .`
