# 1. GitHub

GitHub is a code sharing platform based around `git`.

- login or create an account at [github](https://github.com/)
- find this git repo at [https://github.com/ailomaa/good-practices](https://github.com/ailomaa/good-practices)
- fork the repo (create a copy of the repo for your own account)
- check if you have a ssh key, or create a new one (useful when interacting with the repositories)

## Check if you have a ssh key

Open a terminal (powershell on Windows):
```console
ls ~/.ssh
```

If you see files like you have a key:
```console
id_ed25519
id_ed25519.pub
```

## Create a ssh key

Open a terminal and run:
```console
ssh-keygen
```

Answer the questions, set a strong password.
Then, copy the contents of your *.pub file (your public key) and paste at next step.

## Add the key to Github

Head to [https://github.com/settings/keys](https://github.com/settings/keys).
Select "New SSH Key". Paste the contents of your *.pub key.

## Test your key while cloning your forked repository

You should now be able to use url that starts with git., rather then https://
This only works on repositories where you have privileges.
Use the commands below (replace USERNAME).
When asked for a password, input the password for your ssh key - not your github account:

```
git clone git@github.com:USERNAME/good-practices.git
```
