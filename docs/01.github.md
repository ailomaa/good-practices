# 1. GitHub

GitHub is a code sharing platform based around `git`.

- login or create an account at [github](https://github.com/)
- find this git repo at [https://github.com/ailomaa/good-practices](https://github.com/ailomaa/good-practices)
- fork the repo (create a copy of the repo for your own account)
- check if you have an SSH key, or create a new one (useful when interacting with the repositories)

## Check if you have an SSH key

Open a terminal (or PowerShell on Windows):
```console
ls ~/.ssh
```

If you see files like this it means you already have a key:
```console
id_ed25519
id_ed25519.pub
```

The name can be anything — `id_rsa`, `id_ecdsa` or something you chose
yourself. What matters is the pair: one file, and the same name with `.pub`.

## Create a SSH key

Open a terminal and run:
```console
ssh-keygen -t ed25519
```

Answer the questions, and set a strong passphrase.

Then print your public key and copy it — the whole thing, as one line:
```console
cat ~/.ssh/id_ed25519.pub
```

## Add the key to GitHub

Head to [https://github.com/settings/keys](https://github.com/settings/keys).
Select "New SSH Key". Paste the contents of your *.pub key.

You should now be able to push to GitHub URLs that begin with `git@` rather than
`https://`, given you have the permission to push to the repo.

## Add the key to SSH agent

You can store the SSH key using the SSH agent.
As a result you won't have to type the passphrase for your key every time you use it.

The method for making the agent persist between boots differs per system.

### On Windows (PowerShell)

To perform these changes you have to start PowerShell as admin.
Do `Windows Key + X` and select `Windows Terminal (Admin)` — on Windows 10 the
entry is called `Windows PowerShell (Admin)`.

```console
Set-Service ssh-agent -StartupType Automatic
Start-Service ssh-agent
```

Then, close the admin terminal. Open a regular terminal and do:
```console
ssh-add ~\.ssh\id_ed25519
```

The key is added as the user running the command, which is why this step must
not be done in the admin window. Once added, Windows keeps the key across
reboots until you clear it with `ssh-add -D`.

### On macOS (Terminal.app)

```console
ssh-add --apple-use-keychain ~/.ssh/id_ed25519
```

On macOS the agent does not reload the key at login on its own, so also put
this in `~/.ssh/config`:

```
Host github.com
  AddKeysToAgent yes
  UseKeychain yes
  IdentityFile ~/.ssh/id_ed25519
```

(`--apple-use-keychain` needs macOS 12 or later. On older versions it is `-K`.)

### Verify

```console
ssh-add -l              # the key is loaded in the agent
ssh -T git@github.com   # GitHub recognises it and greets you by name
```
