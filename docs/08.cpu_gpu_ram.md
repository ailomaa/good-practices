# 8. CPU, GPU and RAM

Before you start something big it is worth knowing what the
machine has, what is left of it, and who else is using it.

## What does this machine have?

```console
nvidia-smi -L         # list nvidia GPUs, if there are any
free -h               # RAM usage, in human-readable units
nproc                 # how many CPU cores
lscpu                 # more detail: model, cores, sockets
df -h                 # disk space per filesystem
```

If `nvidia-smi` is not found, the machine has no NVIDIA GPU. Your code will run
on the CPU.

## What is being used right now?

```console
nvidia-smi            # GPU memory and utilisation, plus whose processes
uptime                # load average: last 1, 5 and 15 minutes
free -h               # look at the "available" column
who                   # who else is logged in
```

Compare the load average with `nproc`. A load of 4 on a 32-core machine is
idle; a load of 60 on the same machine means everything is queueing.

For RAM, the number that matters is **available**, not **free**. Linux uses
spare memory for caching and gives it back when a program needs it.

## Watching your own job

For a GPU job, repeat `nvidia-smi` every few seconds:

```console
nvidia-smi -l 5             # refresh every 5 seconds, Ctrl+C to stop
watch -n 5 nvidia-smi       # same idea, one screen that updates
```

Two GPU numbers, and they mean different things:

- **memory used** — how much of the card your job has reserved
- **utilisation %** — how hard it is actually working

A job can hold most of the GPU memory while doing almost nothing, which usually
means it is waiting for data rather than computing.

Checking CPU and RAM usage:

```console
ps -u $USER -o pid,%cpu,%mem,etime,cmd   # just your processes
top                   # live view - q to quit, M sorts by memory, P by CPU
htop                  # nicer, if it is installed
```

## What happens if the computer runs out of resources

Most likely someones process will be killed forecefully by the system.
In the worst case, the server is jammed and is unusable for a time.
