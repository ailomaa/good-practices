# 4. Shell

[Nice short introduction to the Unix shell](https://swcarpentry.github.io/shell-novice/)

## What is a command?

Most commands are small programs in the system. Other commands are a part of
the functionality of the shell (like `exit`).

One very useful command is `which`. You can use it to find out where a program
is located. This is particularly useful when working with custom python environments:

```console
which python3
```

## Command, options and arguments

Every line you type has the same shape: a **command**, then any **options**,
then any **arguments**. The command is the program to run. Options start with
a `-` and change how it behaves. Arguments say what to act on — usually a file
or a directory.

```console
$ ls -l projects
  ^^ ^^ ^^^^^^^^
  |  |  argument
  |  option
  command
```

Options and arguments are often optional, which is why `ls` on its own works.
Everything is separated by spaces, so a file name containing a space has to be
quoted: `less "my train.py"`.

## Typical commands

Here are some typical commands that are very handy to know:

Moving around:

```console
pwd          # where am I
ls           # what is here
ls -l        # more detail: size, date, permissions
ls -a        # also show hidden files (names starting with .)
cd projects  # go into a directory
cd ..        # go up one level
cd           # go home
```

Files and directories:

```console
mkdir data      # make a directory
cp a.txt b.txt  # copy
cp -r data bak  # copy a directory and its contents
mv a.txt b.txt  # move, or rename - same command
rm a.txt        # delete a file - no trash, no undo
rm -r olddir    # delete a directory and its contents
```

Download a file from the internet using `wget`:

```console
wget https://example.org/data.zip
```

Reading text files:

```console
cat train.py      # print the whole file
less train.py     # page through it - q to quit
head train.py     # first 10 lines
tail train.py     # last 10 lines
tail -f output.log # keep printing as the file grows - Ctrl+C to stop
wc -l train.py    # count lines
nano train.py     # edit it - Ctrl+O saves, Ctrl+X quits
```

Searching:

```console
grep error output.log   # print the lines containing "error" in output.log
find . -name "*.csv"    # find files by name, anywhere in your working dir
```


## Getting help

Every command comes with its own documentation.

```console
man ls        # the full manual for ls
ls --help     # a short summary, usually enough
ls -h         # same, on commands that do not support --help
```

## Shell Script

A shell script is a text file holding the same commands you would type by hand.
It is very useful to use shell scripts when having to issue a series of
complicated commands, particularly if doing it often.

Example shell script:
```bash
cd ~/projects/analysis
python3 run.py data.csv
```
Name the file run.sh, and run it:
```console
bash run.sh
```

### Shebang

You may also include a shebang (`#!`) and a path to the shell that should run the
file.
```bash
#!/bin/bash
cd ~/projects/analysis
python3 run.py data.csv
```
This is only useful when wanting to make the file executable and run it
like this:
```console
$ chmod +x run.sh
$ ./run.sh
```
