# 2. Terminal

## Open a terminal

Use the one that is already installed and standard on your system.

| OS | Terminal | How to open |
|---|---|---|
| Windows | **Windows Terminal** (runs PowerShell) | Start menu → "Terminal", or `Win+X` → Terminal |
| macOS | **Terminal.app** | `Cmd+Space` → "Terminal" |
| Linux | (depends) | `Ctrl+Alt+T` |

## Shell

The shell is the program running *inside* the terminal that interprets what you
type.

| OS | Shell |
|---|---|
| Windows | PowerShell |
| macOS | zsh (or bash) |
| Linux | bash |

Check which shell is default on your system (Linux, Mac):

```console
$ echo $SHELL
/bin/bash
```

## The prompt

The prompt is the text the shell prints when it is ready for input, and it looks different on every system:

```console
PS C:\Users\anna>             Windows, PowerShell
anna@Annas-MacBook-Pro ~ %    macOS, zsh
anna@laptop:~/projects$       Linux, bash (Ubuntu)
[anna@server ~]$              Linux, bash (Red Hat)
```

All four say roughly the same things, in different arrangements:

| Part | Meaning |
|---|---|
| `anna` | which user you are |
| `laptop`, `server` | which machine you are on |
| `~/projects`, `C:\Users\anna` | where you are in the file system |
| `~` | your home directory |
| `$`, `%`, `>` | end of the prompt — type after this |

The last character is a convention, not a rule: `$` for a normal user in bash,
`%` in zsh, `>` in PowerShell.

## History

Everything you type is remembered.

| Key | Does |
|---|---|
| `↑` / `↓` | Step back and forward through previous commands |
| `Ctrl+R` | Search history — type a few letters, `Enter` to run, `Ctrl+C`to interrupt |

Use the command `history` to print the whole list.

## Tab completion

Press `Tab` and the shell finishes the word for you — commands, file names,
paths. This is the single biggest speed and accuracy gain available, and it
also confirms a file exists before you act on it.

```console
$ cd Doc<Tab>
$ cd Documents/
```

Behaviour differs:

| Shell | On `Tab` |
|---|---|
| bash (Linux) | Completes as far as unambiguous. `Tab` twice lists all matches. |
| zsh (macOS) | Same, then repeated `Tab` cycles through the matches. |
| PowerShell (Windows) | Cycles through matches one at a time. `Ctrl+Space` shows them all. |

## Keys worth knowing

Some of these do not work on Windows terminals, unless using it to log into a
Linux host.

| Key | Does |
|---|---|
| `Ctrl+C` | Stop the running command |
| `Ctrl+L` | Clear the screen |
| `Ctrl+A` / `Ctrl+E` | Jump to start / end of line |
| `Ctrl+U` / `Ctrl+K` | Delete to start / end of line |
| `Ctrl+D` | End of input; on an empty line, close the shell |
| `q` | Leave a pager (`man`, `less`, `git log`) |
