# 9. Software Development

## Common development loop

1. plan, prototype
2. develop and do preliminary (alpha) testing on client machine
3. do more (beta) testing on production machine and fix any bugs
4. run the final code on the production machine

## Best practices

- keep code in a git repo
- use `git` to sync code between your client computer and server
- use `scp` or `rsync` to move data between client and server
- use `tmux` to run long running tasks on server

## Working with git

Use a single repository containing all code changes.
Do not copy code.

### Example: Start from scratch

- create dir
- do `git init`
- write some code, commit
- push to cloud

### Example: Base on existing code

- fork the repo
- git clone the repo
- do some changes and git commit
- push to cloud

### Example: Collaborate

- someone creates a repo and pushes to cloud
- others do git clone
- everyone develops in a separate branches
- merge the separate branches with the main when feature-ready
    - conflicts happen when developers work on the same files and need to be manually resolved
